# Tenant Administrator Maintenance

## Product decision

租户创建完成后，租户管理员必须可以从租户列表通过独立“管理员”入口继续维护，不能要求重新编辑或重建租户。

- 一个租户可存在多个租户管理员，管理界面应列出全部符合租户管理员角色的账号。
- 管理员资料编辑与密码重置必须分离，避免普通资料保存误触安全操作。
- 资料编辑仅开放姓名、邮箱、手机号；用户名和租户管理员身份只读。
- 密码重置必须进行强度校验、两次输入一致校验和二次风险确认，成功后撤销该账号现有会话。

## Backend boundary

- 所有管理员查询、资料修改和密码重置均由后端校验租户存在、用户归属目标租户且具备租户管理员角色。
- 平台管理员执行跨租户治理时使用系统查询上下文，但不能绕过目标租户和管理员角色验证。
- 密码只保存哈希，不返回、不记录明文。
- 新增操作权限后必须同步 mock 菜单按钮权限和 Casbin 角色策略。
