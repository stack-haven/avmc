# 模块归类

本目录用于给 Ark Tech Platform 上的业务产品服务提供模块归类入口。

## 历史归档

应用版本管理中心（AVMC）服务的模块归类已随产品文档归档到 `docs/archive/product-avmc/`。

新增业务产品服务时，应参考该目录中的模块归类方式建立新的模块入口文件。

## 当前平台模块完善需求

- [租户管理人工测试完善需求](./租户管理-人工测试完善需求.md) — 套餐菜单权限独立配置、生命周期显示、租户新增/编辑分步体验
- [用户与部门管理一体化体验完善需求](./用户与部门管理-一体化体验完善需求.md) — 左侧部门树、右侧用户管理、部门联动筛选及删除前人员转移；产品决策已确认，开发中
