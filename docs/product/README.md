# 产品需求文档目录

本目录用于存放 Ark Product Services 的产品需求、字段、验收标准和迭代规划。

产品服务的身份和资料入口先在 `docs/services` 中登记；具体需求可继续放在本目录或服务目录内，但必须保持入口清晰。

## 当前状态

应用版本管理中心（AVMC）的旧产品需求已归档到 `docs/archive/product-avmc/`，包括：

- `00-AVMC-产品需求总览.md`
- `00-AVMC-迭代开发规划.md`
- `00-AVMC-模块划分与工具分析.md`

新增产品服务时，可参考归档资料的表达方式，但实现边界必须以 `docs/architecture` 和 `docs/services` 当前文档为准。
