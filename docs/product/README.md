# AVMC 产品文档

本目录只放当前生效的产品需求和迭代开发主文档。历史需求、需求分析、项目规划、UI 原型等旧资料已归档到 `docs/archive/product-202501`。

## 当前主文档

- `00-AVMC-产品需求总览.md`：产品目标、用户角色、MVP/P1/P2 范围、核心模块需求、字段和验收标准。
- `00-AVMC-迭代开发规划.md`：后续迭代顺序、每次迭代开发流程、子仓库提交规则、测试验收和风险应对。
- `00-AVMC-模块划分与工具分析.md`：模块边界、当前代码基础、工具链、验证命令和每个模块的最小交付件。

## 使用规则

- 新功能需求优先补充到 `00-AVMC-产品需求总览.md`。
- 后续阶段、优先级和开发流程调整优先补充到 `00-AVMC-迭代开发规划.md`。
- 模块边界、工具链和执行策略调整优先补充到 `00-AVMC-模块划分与工具分析.md`。
- 如果需要参考旧文档，只从 `docs/archive/product-202501` 查阅，并以当前代码和 `.codex` 规则校验。
- 不要把旧文档重新混入本目录，避免 Codex 检索时误判当前事实来源。
