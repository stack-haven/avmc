## 一、设计目标

新产品上线只需在注册中心配置，不改中台代码。产品开发团队按 6 步流程完成接入。

```mermaid
flowchart TB
    DEV["产品开发团队"] --> STEP1["① 注册产品基本信息<br/>编码/名称/描述/图标"]
    STEP1 --> STEP2["② 注册菜单树<br/>层级结构/路由/权限点"]
    STEP2 --> STEP3["③ 注册定价方案<br/>档位表/月付/年付价格"]

    STEP1 -.->|"纯配置<br/>立即生效"| CONFIG["配置类 (3 项)"]
    STEP2 -.-> CONFIG
    STEP3 -.-> CONFIG

    STEP3 --> STEP4["④ 注册配额维度<br/>维度名/限额/超额策略"]
    STEP4 --> STEP5["⑤ 注册开通表单<br/>字段定义/校验规则"]
    STEP5 --> STEP6["⑥ 平台审核"]

    STEP4 -.->|"需开发接入"| DEV_WORK["开发类 (3 项)"]

    STEP6 -.-> DEV_WORK

    STEP6 -->|"✅ 通过"| ONLINE["产品上线<br/>· 代理可授权<br/>· 客户可选购<br/>· 菜单动态展示<br/>· 计费自动接入"]
    STEP6 -->|"❌ 退回"| DEV
```

## 二、注册数据契约

```mermaid
erDiagram
    PRODUCT_LINE {
        string product_code PK "产品编码 (GEO/CRM/ERP)"
        string product_name "产品名称"
        string description "产品描述"
        string icon "产品图标 URL"
        string status "enabled|disabled|in_development"
    }

    PRODUCT_MENU {
        string menu_id PK "菜单唯一标识"
        string product_code FK "所属产品"
        string parent_id "父菜单 (树形)"
        string menu_name "菜单名称"
        string route_path "路由路径"
        string permission_key "权限标识"
        int sort_order "排序"
    }

    PRODUCT_PLAN {
        string plan_id PK "方案标识"
        string product_code FK "所属产品"
        string plan_name "方案名称"
        decimal monthly_price "月付价格"
        decimal yearly_price "年付价格"
    }

    PRODUCT_QUOTA {
        string quota_id PK "配额标识"
        string product_code FK "所属产品"
        string plan_id FK "所属方案"
        string dimension "配额维度名"
        int limit_value "配额值"
        string overage_policy "soft|hard"
        decimal overage_unit_price "超额单价"
    }
```

## 三、菜单动态拼装

```mermaid
sequenceDiagram
    actor User as 用户
    participant Frontend as 前端
    participant GW as API 网关
    participant PR as 产品注册中心
    participant Auth as 认证中心

    User->>Frontend: 登录
    Frontend->>Auth: POST /auth/login
    Auth-->>Frontend: Token + 用户信息

    Frontend->>PR: GET /products/menus?tenant_id=T_A
    PR->>PR: 查询租户已开通产品线
    PR->>PR: 加载各产品菜单树
    PR->>PR: 按用户角色过滤权限
    PR-->>Frontend: 合并菜单树

    Frontend->>Frontend: 渲染统一控制台<br/>顶部: 产品线切换器<br/>侧栏: 当前产品菜单
```

## 四、产品接入检查清单

产品团队接入平台需完成：

| # | 项目 | 类型 | 说明 |
|:---:|------|:---:|------|
| 1 | 产品基本信息注册 | 配置 | product_code/name/icon/description |
| 2 | 菜单树注册 | 配置 | 层级结构 + 权限点 + 路由 |
| 3 | 定价方案注册 | 配置 | 档位 + 月付/年付价格 |
| 4 | 配额维度注册 | 开发 | 维度定义 + 档位限额 + 超额策略 |
| 5 | 开通表单注册 | 开发 | 客户开通时字段和校验 |
| 6 | 认证接入 | 开发 | 调用认证中心验证 Token |
| 7 | 用量上报接入 | 开发 | 调用计费引擎上报用量 |
| 8 | 通知事件接入 | 开发 | 调用通知中心推送事件 |
| 9 | 文件存储接入 | 开发 | 调用文件中心上传/下载 |
| 10 | 审计日志接入 | 开发 | 调用审计中心记录操作 |
