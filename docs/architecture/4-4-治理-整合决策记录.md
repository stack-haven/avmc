## 背景

Ark Engine（方舟引擎）方案于 2026 年 7 月并入当前 Ark Tech Platform 文档体系。本文档记录整合决策，已生效。

---

## 决策

### 命名

项目统一命名为 **Ark Tech Platform**。

### 分层

| 层 | 来源 | 说明 |
|---|------|------|
| Ark Platform Foundation | 当前代码 + Ark 技术中台 | 多租户、权限、套餐、审计、任务、文件、通知 |
| Ark Business Platform | Ark 业务中台 | 产品注册、客户运营、订阅计费、渠道、佣金（路线图） |
| Ark Product Services | 当前 + Ark 产品层 | GEO Engine、AI Agent、App Version Management |

---

## 保留的 Ark Engine 设计

- 多产品 SaaS 四层架构
- 产品注册中心（6 步接入流程）
- 产品菜单、权限、套餐、配额的注册思想
- 客户开通、代客运营、健康度模型
- 订阅、计费、账单、用量、超额策略
- 渠道代理、佣金结算
- API 边界、安全架构、租户隔离
- 单机→可扩展部署演进路线
- NFR 指标体系

---

## 不直接照搬的内容

| 项目 | 原因 |
|------|------|
| 不强制迁移 PostgreSQL/RLS | MySQL 满足当前需求 |
| 不强制引入 Kong/APISIX API Gateway | Kratos 中间件已覆盖 |
| 不强制引入独立搜索/观测/计费服务 | 大仓模块化优先 |
| 不用 Node/BullMQ/Nuxt 替代 | 保持 Go/Kratos/Vben 工程基线 |
| 不一次性实现全部商业能力 | 按 P1→P3 分阶段 |
