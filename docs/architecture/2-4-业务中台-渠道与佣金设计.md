## 一、渠道模型

```mermaid
graph TB
    subgraph Platform["平台方"]
        Products["产品池<br/>GEO / SEO / CRM / ERP"]
    end

    subgraph Agent["代理层"]
        A1["代理 A (省总代)<br/>授权: 全产品"]
        A2["代理 B (GEO 专代)<br/>授权: GEO"]
        A3["代理 C (综合代)<br/>授权: GEO + CRM"]
    end

    subgraph Salesperson["业务员层"]
        S1["业务员 A1<br/>可卖: 全产品 (继承)"]
        S2["业务员 B1<br/>可卖: GEO (继承)"]
        S3["业务员 C1<br/>可卖: GEO + CRM (继承)"]
    end

    subgraph Customer["客户层"]
        C1["客户 1"]
        C2["客户 2"]
        C3["客户 3"]
    end

    Products -->|"配置授权"| Agent
    Agent -->|"自动继承"| Salesperson
    Salesperson -->|"分配服务"| Customer
```

- **代理** → 平台授权产品线
- **业务员** → 自动继承所属代理的产品授权
- **客户** → 分配给业务员服务

## 二、代理生命周期

```mermaid
stateDiagram-v2
    [*] --> APPLYING: 代理提交入驻申请

    APPLYING --> REVIEWING: 平台收到申请
    REVIEWING --> OPENED: 审核通过
    REVIEWING --> REJECTED: 审核不通过
    REJECTED --> APPLYING: 重新提交

    OPENED --> OPERATING: 缴纳保证金

    OPERATING --> WARNING: 季度业绩不达标
    WARNING --> OPERATING: 改善达标
    WARNING --> DEMOTED: 连续不达标 → 降级为非独家

    OPERATING --> EXIT: 代理申请退出
    OPERATING --> EXPULSION: 违规清退
    EXIT --> CLOSED: 结算完成
    EXPULSION --> CLOSED: 扣押保证金
```

## 三、佣金结算引擎

### 多产品分佣模型

```mermaid
flowchart TB
    PAYMENT["客户 XX公司 本月付费 ¥14,000"] --> SPLIT["按产品线拆分"]

    SPLIT --> GEO["GEO Pro: ¥9,000"]
    SPLIT --> CRM["CRM Starter: ¥5,000"]

    GEO --> GEO_CALC["GEO 佣金计算<br/>判断首单/续费 → 查佣金比例"]
    CRM --> CRM_CALC["CRM 佣金计算<br/>判断首单/续费 → 查佣金比例"]

    GEO_CALC --> GEO_RESULT["代理 GEO 佣金<br/>业务员 GEO 提成"]
    CRM_CALC --> CRM_RESULT["代理 CRM 佣金<br/>业务员 CRM 提成"]

    GEO_RESULT --> MERGE["合并结算单"]
    CRM_RESULT --> MERGE
```

### 佣金比例配置

| 产品线 | 代理类型 | 首单佣金 | 续费佣金 | 业务员建议提成 |
|--------|:------:|:------:|:------:|:------------:|
| GEO | 独家 | 50% | 20% | 佣金的 50-70% |
| GEO | 非独家 | 40% | 15% | 佣金的 50-70% |
| SEO | 通用 | 40% | 15% | 佣金的 50% |
| CRM | 通用 | 60% | 25% | 佣金的 60% |
| ERP | 通用 | 30% | 10% | 佣金的 50% |

> CRM 佣金最高 — 作为新推产品以高佣金激励渠道推广。佣金比例是业务杠杆，应可配置。

## 四、月度结算流程

```mermaid
sequenceDiagram
    participant System as 结算引擎
    participant Billing as 计费数据
    participant Agent as 代理
    participant Finance as 平台财务

    Note over System: 每月 1 号 00:00 自动触发

    System->>Billing: 拉取上月所有已付账单
    Billing-->>System: 返回 (按租户+产品线分列)

    System->>System: 按代理分组<br/>按产品线独立计算<br/>区分首单/续费

    System->>System: 生成结算预览单<br/>· 代理总佣金<br/>· 业务员分佣明细<br/>· 各产品线佣金明细

    System->>Agent: 推送结算预览 (每月 1 号)
    Agent->>System: 核对 (有异议 → 提交工单)

    alt 无异议
        System->>Finance: 每月 5 号 生成正式结算单
        Finance->>Agent: 每月 10 号 打款
    else 有异议
        System->>Finance: 标记争议，人工处理
        Finance->>Agent: 协商解决
        System->>System: 按协商结果调整
    end
```
