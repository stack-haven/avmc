# 多租户参数配置中心设计

日期：2026-06-30
状态：首期生效
范围：项目开发底座参数管理，不包含密钥管理

## 1. 目标

参数配置中心为底座和后续业务服务提供统一的运行参数模型：

- 平台定义参数键、类型、默认值和租户覆盖策略。
- 租户只维护允许覆盖的参数值。
- 调用方直接读取最终有效值，不自行合并默认值和租户值。
- 参数变更通过版本化缓存键立即失效，不扫描和批量删除缓存。
- 参数类型、租户边界和平台控制面权限由后端强制保证。

## 2. 明确边界

首期只存储非敏感运行参数。以下内容禁止写入参数中心：

- 密码和口令。
- API Key、私钥和凭据。
- Access Token、Refresh Token。
- 其他需要加密、轮换、授权读取和访问审计的秘密值。

参数键以 `.password`、`.secret`、`.api_key`、`.private_key`、`.access_token` 等敏感后缀结束时，后端直接拒绝。密钥类数据后续由独立密钥管理能力承接，不能通过增加一个“敏感”布尔字段后明文落库。

## 3. 领域模型

### 3.1 ParameterDefinition

平台全局参数定义：

- `key`：全局唯一，使用小写分段格式，例如 `system.page_size`。
- `name`：管理端名称。
- `value_type`：字符串、整数、布尔值或 JSON。
- `default_value`：平台默认值。
- `tenant_overridable`：是否允许租户覆盖。
- `status`：停用后不进入运行时解析结果。
- `sort`、`description`：管理属性。

参数定义是平台控制面资源，不携带 `tenant_id`。

### 3.2 TenantParameterOverride

租户覆盖值：

- `tenant_id`
- `definition_id`
- `value`
- `updated_by`

`tenant_id + definition_id` 唯一。该实体使用统一 Ent tenant privacy policy，普通租户不能读取、更新或删除其他租户覆盖值。

### 3.3 ResolvedParameter

运行时解析结果：

- 参数定义信息。
- 最终有效值。
- 值来源：平台默认或租户覆盖。
- 最后更新时间。

调用方不直接读取覆盖表。

## 4. 类型与变更规则

- 字符串：保留原值。
- 整数：必须可解析为有符号 64 位整数。
- 布尔值：只能是 `true` 或 `false`。
- JSON：必须是有效 JSON。
- 单值大小上限 16 KiB。
- 已存在租户覆盖值时，不允许修改参数类型。
- 参数不允许租户覆盖时，设置覆盖值返回 403。
- 参数定义存在租户覆盖值时，不允许删除。
- 重置覆盖值是幂等操作，删除覆盖记录后自动回退平台默认值。

## 5. 权限模型

平台控制面操作：

- 参数定义查询、创建、修改和删除。
- 指定租户参数查询、设置和重置。

租户数据面操作：

- 查询当前租户最终参数。
- 设置当前租户允许覆盖的参数。
- 重置当前租户覆盖值。

平台控制面操作同时经过 Casbin 和 `platform_operator` 中间件。当前租户接口始终从签名认证上下文读取 `tenant_id`，不接受客户端指定目标租户。

## 6. 缓存一致性

运行时解析结果缓存在 Redis，缓存键由三个维度组成：

```text
platform:admin:parameter:resolved:{tenant_id}:{global_version}:{tenant_version}
```

版本键：

```text
platform:admin:parameter:global_version
platform:admin:parameter:tenant:{tenant_id}:version
```

失效规则：

- 参数定义创建、更新、删除：递增 `global_version`，所有租户在下次读取时切换到新键。
- 租户覆盖设置、重置：只递增目标租户版本。
- 缓存 TTL 为 30 分钟，用于回收旧版本键。
- Redis 故障时降级读取数据库，不影响参数管理主流程。

该方案避免全量扫描 Redis，也避免平台默认值变化时逐租户删除缓存。

## 7. 管理端交互

参数配置页分为：

- 平台参数定义：只有具备平台定义权限码的用户可见。
- 当前租户参数：平台租户和普通业务租户均可使用。

普通租户不会请求平台定义接口。值编辑器根据参数类型使用整数输入、布尔开关或文本编辑控件；恢复默认值需要二次确认。

## 8. 服务边界

首期完成管理面和当前登录租户的解析 API。后续独立业务微服务接入前，还需要完成：

- 服务身份与应用凭证。
- 内部配置读取 API 或客户端 SDK。
- 配置变更事件/Webhook。
- 本地只读缓存和故障期间的最后可用快照。

业务服务不得直接连接底座参数表或 Redis。

## 9. 验收标准

- 平台可创建四种类型的参数定义。
- 类型不合法的默认值和覆盖值均被拒绝。
- 普通租户不能访问平台定义和指定租户接口。
- 普通租户只能覆盖本租户且允许覆盖的参数。
- 租户 A 的覆盖值不影响租户 B。
- 重置后立即恢复平台默认值。
- 平台默认值变化后所有租户缓存立即切换版本。
- 单租户覆盖变化只刷新该租户缓存。
- 敏感参数键无法写入。
- 管理端中英文文案和类型化接口检查通过。
