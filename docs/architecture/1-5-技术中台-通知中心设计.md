## 二、通知模板

```text
notification_template {
    code             "模板编码 (如 tenant.created)"
    name             "模板名称"
    channel          "in_app | email | sms"
    title_template   "标题模板 (支持变量 {{.var}})"
    content_template "内容模板 (支持变量)"
    variable_schema  "变量定义 JSON Schema"
    locale           "zh-CN | en-US"
    status           "enabled | disabled"
}
```

### 变量替换示例

```text
模板: "您的 {{.product_name}} 套餐 {{.dimension}} 已使用 {{.used}}/{{.limit}}"

渲染: "您的 GEO Engine 套餐 文章数 已使用 29/30"
```

## 三、发送流程

```mermaid
sequenceDiagram
    actor Admin as 平台管理员
    participant API as 通知 API
    participant Template as 模板引擎
    participant Task as 异步任务中心
    participant Worker as Worker
    participant DB as 数据库

    Admin->>API: POST /notify/send { template_code, recipients, variables }
    API->>Template: 匹配模板 + 校验变量
    Template-->>API: 模板有效，变量完整

    API->>Task: Enqueue(notification.in_app.send, payload)
    Task-->>API: task_id

    API-->>Admin: { task_id, status: "queued" }

    Note over Worker: 异步执行

    Worker->>DB: 根据 recipients 生成 notification_messages
    Worker->>DB: 更新 task 状态 SUCCEEDED
```

## 四、已读状态模型

```mermaid
stateDiagram-v2
    [*] --> UNREAD: 消息生成
    UNREAD --> READ: 用户查看/标记已读
    READ --> [*]

    note right of UNREAD: GET /notify/my-messages
    note right of READ: POST /notify/read/{id}
```

- 单条已读和批量已读幂等
- 未读数实时查询当前用户和租户
- 消息按创建时间倒序
