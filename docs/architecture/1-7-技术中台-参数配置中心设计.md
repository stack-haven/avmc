# 参数配置中心设计

日期：2026-07-22
状态：已验证
范围：`backend-service/app/platform/service`

---

## 一、设计目标

平台统一管理参数定义和默认值，租户可按需覆盖。调用方获取"最终解析值"，无需自行合并。

```mermaid
flowchart TB
    Platform["平台管理员"] -->|"定义参数"| Def["ParameterDefinition<br/>key + 类型 + 默认值 + 是否允许覆盖"]
    Tenant["租户管理员"] -->|"按需覆盖"| Override["TenantParameterOverride<br/>覆盖值"]

    Def --> Resolver["参数解析器"]
    Override --> Resolver
    Resolver -->|"返回最终值"| Caller["业务调用方<br/>GET /params/resolved"]
```

---

## 二、核心实体

```mermaid
erDiagram
    ParameterDefinition ||--o{ TenantParameterOverride : "被覆盖"

    ParameterDefinition {
        string key PK "参数键 (全局唯一, 小写点分)"
        string name "参数名称"
        string value_type "string|int|bool|json"
        string default_value "默认值"
        bool tenant_overridable "是否允许租户覆盖"
        string status "enabled|disabled"
        int sort "排序"
        string description "描述"
    }

    TenantParameterOverride {
        string tenant_id FK "租户"
        string definition_id FK "参数定义"
        string value "覆盖值"
        string updated_by "更新者"
    }
```

## 三、参数读取

```mermaid
sequenceDiagram
    participant Caller as 业务模块
    participant API as 参数配置 API
    participant Cache as Redis
    participant DB as 数据库

    Caller->>API: GET /params/resolved?keys=upload.max_size,notification.enabled
    API->>Cache: 查询缓存<br/>key=param:resolved:<tenant_id>:<global_ver>:<tenant_ver>
    alt 缓存命中
        Cache-->>API: 已解析的参数
    else 缓存未命中
        API->>DB: 查询 ParameterDefinition + TenantParameterOverride
        API->>API: 合并: override ?? default
        API->>Cache: 写入缓存
    end
    API-->>Caller: { "upload.max_size": "100MB", "notification.enabled": "true" }
```

## 四、安全约束

| 规则 | 说明 |
|------|------|
| **类型锁定** | 参数定义创建后 `value_type` 不可变更 |
| **覆盖保护** | 存在覆盖值时，不允许修改参数类型 |
| **删除保护** | 存在覆盖值的定义不允许删除 |
| **覆盖权限** | `tenant_overridable=false` 时设置覆盖返回 403 |
| **敏感键拒绝** | key 含 `.password` `.secret` `.api_key` `.private_key` 后缀拒绝创建 |
| **平台隔离** | ParameterDefinition 无 `tenant_id`（平台控制面资源） |

## 五、缓存一致性

```mermaid
flowchart TB
    Change["参数变更事件<br/>定义更新|覆盖更新|删除"] --> Incr["递增版本号<br/>global_version 或 tenant_version"]
    Incr --> Invalidate["缓存 key 变更<br/>旧数据自然过期"]
    Invalidate --> NextRead["下次读取<br/>触发 DB 查询+缓存重建"]

    style Incr fill:#e8f5e9
```

- `global_version` 变更 → 所有租户缓存失效
- `tenant_version` 变更 → 仅该租户缓存失效
- 缓存 TTL 30 分钟 + 版本 key 双重过期保护
- Redis 不可用时降级为数据库直读
