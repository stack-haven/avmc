# 02 · 信息架构与页面规格

> 来源：原规范 §4（页面信息架构与交互要求）
> 上游：[01 产品范围](01-product-scope.md) · 相关：[03 设计系统](03-design-system.md)、[07 SEO](07-seo-geo.md)

俄语路由与文案为**面向俄罗斯市场**。下列路由在实现时一律使用俄语可见文案 + 拉丁化 slug。

---

## 1. 全站导航

| 顺序 | 俄语文案 | 路由 | 说明 |
|---|---|---|---|
| 1 | Каталог | `/catalog` | 商品目录 |
| 2 | Среды обитания | `/habitats` | 环境方案 / 成品方案 |
| 3 | Конфигуратор | `/configurator` | 环境设计器 |
| 4 | Гиды | `/guides` | 指南 / 文章 |
| 5 | О бренде | `/about` | **只有存在真实内容时才上线**，否则不显示该入口 |

### 1.1 Header 组成

- 品牌 Logo（真实素材到位前使用文字标识，不用占位 Logo 冒充品牌）
- 目录 / 方案 / 设计器入口
- 搜索（**仅当真实实现可用时显示**）
- 购物车入口（Demo 状态需可见标注）
- 移动端导航（汉堡 + 抽屉）

### 1.2 禁止项

- 不显示无效的登录、收藏、比较、语言切换、搜索按钮。
- 未实现的功能必须**隐藏或明确禁用并说明**，不能留一个点了没反应的按钮。

## 2. 首页 `/`

区块顺序**固定**，与 [05 §2 Slot 定义](05-content-ops.md#2-固定首页-slot) 一一对应：

1. Header
2. Hero 主视觉（`home.hero`）
3. 可证实服务信息条（`home.trust_strip`）— 未核验的配送/退换承诺**不展示**
4. 双入口卡片（`home.entry_cards`）
   - A：`Собрать террариум`（设计我的饲养环境）→ 面向新手与组合用户
   - B：`Смотреть каталог`（浏览全部商品 / 专业选购）→ 面向直接选购用户
5. 热门分类（`home.popular_categories`）
6. 精选商品（`home.featured_products`）
7. 环境方案（`home.habitat_bundles`）
8. 设计器推广 Banner（`home.configurator_banner`）
9. 选购指南（`home.buying_guides`）
10. Footer

### 2.1 Hero 要求

- 清晰主标题 + 副标题 + 主 CTA；
- 强调**专业环境搭配**与**标准产品选择**；
- 不使用虚构销量、客户数、专家认证、"俄罗斯第一"等无法证实的表述。

## 3. 商品目录 `/catalog`、`/catalog/:category`

### 3.1 SSR 首屏必须输出

分类标题、分类简介（若有）、商品名称、价格（若已确认）、可售状态（若可用）、商品链接。

### 3.2 交互

- 分类 + 筛选 + 排序 + 分页或可控"加载更多"；
- 筛选项**只能来源于真实商品 schema 支持的字段**，不预设不存在的参数；
- URL query 可复制分享，参数顺序规范化，避免无意义重复 URL。

### 3.3 索引策略

- 默认不让大量低价值组合筛选 URL 进入索引；
- 使用 canonical / noindex 或规范化 URL（具体策略在 [07 §5](07-seo-geo.md#5-url-与索引策略) 落地）。

### 3.4 必须覆盖的状态

空结果、加载失败、无库存、筛选重置——每个状态都要有明确 UI，不能只剩白屏。

### 3.5 排序正确性

排序字段与价格顺序由后端提供，或前端基于**已加载完整数据**正确实现；**不得在分页子集上假装全局排序**。

## 4. 商品详情 `/products/:slug`

### 4.1 必须展示（有数据时）

- 真实主图 + 辅助图、名称、SKU/型号；
- 当前价格与币种（RUB，来自 API 返回）；
- 可售状态、规格、尺寸（公制）；
- 材料、结构、通风/开口方式等产品实际字段；
- 适用条件与**已验证**的兼容商品；
- 包装清单、安装/清洁说明（真实资料存在时）；
- 相关商品 / 组合建议；
- 加入购物车（第一版仅 demo 状态）；
- 加入设计器（**仅当商品是可配置标准模块时**显示）；
- 面包屑与可理解的页面标题。

### 4.2 禁止

- 不得写死"库存充足""当天发货""免费配送""保修"等未确认承诺。
- 无真实价格时显示 `Цена по запросу`（价格待确认/联系咨询），**不得用虚构价格让用户误以为可购买**。

## 5. 环境方案 `/habitats`、`/habitats/:slug`

### 5.1 详情必须清楚区分

- 适用爬宠 / 适用条件（需经专业资料核实）；
- 环境目标与使用场景；
- 方案图片（实拍 / 示意图**必须标明**）；
- 组成模块及其 SKU、数量、尺寸、材料；
- 兼容性说明；
- 总价（**仅在所有价格可获得且计算规则明确时**才显示）；
- 状态：可直接购买 / 可加入设计器 / 需人工确认。

### 5.2 禁止

- 不得把未经验证的组合描述为适合某一物种。
- 饲养环境相关的健康、温度、湿度、UVB、照明建议必须基于可靠资料并标明物种差异；不得为 SEO 编造饲养建议。

## 6. 设计器 `/configurator`

**第一版目标：标准模块 + 2D/平面预览 + 结构化清单。不做任意 3D 建模。**

### 6.1 桌面布局（三栏）

| 区域 | 内容 |
|---|---|
| 左 | 标准模块目录 / 分类 / 筛选 |
| 中 | 2D / 平面组合预览 |
| 右 | 选中模块属性、规格、数量、清单、估算价格（有可靠数据时） |

底部或侧边：保存、清空、加入演示购物车、咨询人工确认。

### 6.2 移动端

- 分步流程（Stepper），不做三栏压缩；
- 底部固定主操作区；
- 选中模块、尺寸、数量、总清单**始终可查看**。

### 6.3 规则

1. 只能加入**已注册**的标准模块；
2. 每个模块声明允许的连接点 / 兼容关系 / 尺寸限制；
3. 兼容性由后端规则或**经过测试的共享规则**定义，前端不得猜测；
4. 不兼容组合必须显示原因并阻止确认，或明确标记"需人工确认"；
5. 不允许任意输入尺寸后直接显示"可生产"；
6. 价格估算必须标明"估算"及数据来源/更新时间；**价格缺失时不显示误导性总价**；
7. 设计结果第一版可存浏览器本地，但必须经 repository / state 层封装，**组件不得直接读写 localStorage**；
8. 必须测试：页面刷新、空设计、模块删除、重复模块、错误组合、移动端操作；
9. 必须提供**可访问的列表式清单**，不能只靠图形表达信息。

## 7. 购物车 `/cart`

第一版为**前端演示购物车**：

- 加入 / 删除商品、修改数量、显示清单；
- 必须明确标记"演示功能，不会创建真实订单或发起支付"；
- **不得**显示"支付成功""订单已创建"；
- **不得**收集银行卡、支付密码等敏感信息；
- 未来接真实下单时，价格/库存/可售/权限/幂等必须由 Go 后端校验，客户端金额不可信。

## 8. 指南 `/guides`、`/guides/:slug`

- 以解决具体用户问题为主，不以关键词堆砌为目标；
- 每篇指南包含：清楚标题、摘要、正文、更新时间、作者/审核信息（仅真实存在时展示）、相关产品/方案；
- 物种相关内容需要可靠来源、适用范围与免责声明/注意事项；
- 内容须由内容系统或**仓库结构化内容**管理，**禁止把文章硬编码在页面组件内**；
- 支持 canonical、面包屑、文章结构化数据（仅字段真实时输出）。

## 9. 运营原型 `/admin/homepage` 与样式页 `/style-guide`

| 页面 | 要求 |
|---|---|
| `/admin/homepage` | 运营配置原型；开发期可用 Mock Repository / localStorage，但**必须显示"Demo / 本地预览"**，不得冒充已接入生产中台；**不得对匿名用户开放真实管理能力** |
| `/style-guide` | 展示 Tokens、基础组件、业务组件与全部交互状态；生产是否公开由部署配置决定 |

> 真实发布操作必须有鉴权与审计。第一版这些页面**不是**生产运营后台。

## 10. 页面 → 依赖清单（实现顺序参考）

| 页面 | 依赖 Repository | 关键组件 | metadata 要求 |
|---|---|---|---|
| `/` | Homepage, Product, Category, Habitat, Guide | `SectionRenderer` + 9 类 Section | 品牌 + 核心品类 + 价值主张 |
| `/catalog` | Category, Product | `ProductGrid`, `ProductCard` | 分类名 + 真实商品类别 |
| `/products/:slug` | Product | `ProductGallery`, `ProductPrice`, `AvailabilityBadge`, `ProductSpecTable` | 商品名 + 关键规格 |
| `/habitats/:slug` | Habitat, Product | `HabitatBundleCard` | 方案名 + 适用场景 |
| `/configurator` | Product（模块）, Configurator rules | `ConfiguratorModuleCard`, `ConfiguratorCanvas2D` | 介绍内容可索引，交互态 noindex |
| `/cart` | Cart store | — | `noindex` |
| `/guides/:slug` | Guide | `GuideCard` | 具体问题/主题 |
| `/admin/homepage` | Homepage（draft） | Section 编辑器 | `noindex` + 鉴权 |
| `/style-guide` | — | 全部基础组件 | `noindex`（默认） |
