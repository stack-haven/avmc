# 08 · 俄语本地化与合规

> 来源：原规范 §9（俄语市场与用户体验本地化）
> 相关：[07 SEO §6](07-seo-geo.md#6-俄语内容策略seo-视角)、[11 Open Items](11-open-items.md)

## 1. 基础要求

| 项 | 规则 |
|---|---|
| 默认语言 | 俄语（`ru-RU`）；已启用三语 `ru / zh / en`（`prefix_except_default`），`hreflang` 按语言输出 |
| 货币 | 卢布 `RUB`（`₽`），仅显示后端真实价格 |
| 单位 | 公制（mm / cm / kg / °C） |
| 日期/数字 | 遵循俄语用户习惯（`DD.MM.YYYY`、空格千分位、逗号小数） |
| 按钮/导航文案 | **必须人工校对**，禁止中文直译 |
| 字体 | 需支持 Cyrillic；避免字体子集缺失导致方块 |

## 2. 排版与交互注意

- 俄语单词长（`инфракрасный`、`терморегулятор`、`влагостойкий`），导航、按钮、表格列宽必须测试**长词换行**，禁止硬编码固定宽度。
- 避免全大写（`УФ-ЛАМПА` 类排版可读性差），除非品牌明确要求。
- 数字与单位之间用不换行空格（`60 см`、`1 200 ₽`）。
- 复数变形：`1 товар / 2 товара / 5 товаров` —— 商品计数、库存提示必须用 plural 规则，不能简单拼 `s`。

## 4. 法律与政策类（**未确认前不得输出**）

- 支付方式、配送范围/价格/时效、退换货规则、保修；
- 税务与消费者权益声明；
- 隐私政策、个人数据处理与 Cookie 同意；
- 经营主体名称、法定地址、联系方式。

处理方式：这些内容**必须**来自真实经营主体与专业核实。未确认前：

1. 页面不显示对应承诺；
2. Footer 可保留占位入口但**不得**链接到虚构政策文本；
3. 在 [11 Open Items](11-open-items.md) 登记阻塞项。

## 5. 不得把外部能力说成自有能力

- 不得把朋友现有平台、仓库或供应商资源描述成 YOMSP 已拥有的能力，除非合作关系、可用库存与履约责任已**书面确认**。
- 不得显示"俄罗斯本地发货""本地仓现货"等未经确认的文字。

## 6. 内容校对责任

若暂时没有可靠的俄语编辑能力，**必须把需要人工校对的内容列为上线阻塞项**，并在 [11](11-open-items.md) 中明确责任人（待指派）。

## 7. 验收要点

- [ ] 360px 宽度下所有俄语长词不溢出、不截断语义
- [ ] 所有可见文案无中文残留（构建期 grep 断言 `.vue` 中无 CJK 硬编码文案）
- [ ] 商品计数、单位、日期符合俄语习惯
- [ ] 无虚构政策文本、无未确认承诺
- [ ] 字体 Cyrillic 覆盖完整
