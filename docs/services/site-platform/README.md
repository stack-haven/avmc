## 定位

**多站点内容 + 目录 + 展示编排 + 发布** 的通用产品服务。一个站点（Site）= 一个独立品牌站，
共享同一套后端能力；YOMSP 是第一个站点，不是特例代码。

- 不承接平台横向能力：租户、用户、认证、会话、套餐、配额、审计、文件、通知全部复用 `platform/service`；
- 不与 GEO Engine 重叠：GEO 负责**生产**内容（AI 生成/后处理/追踪），本服务负责**承载、编排、发布**内容；
  GEO 产出的实体通过本服务 admin API 写入，不反向依赖；
- 不承接交易：订单/支付/库存属后续 commerce 阶段，本设计只预留 seam（见 `01` §9）。

## 为什么是「产品」而不是「业务中台」

| 判定 | 结论 |
|---|---|
| 是否服务于**其他产品**（Evie/GEO/AI Agent 等）？ | 否——它服务的是「站点」这一业务形态，不是给别的产品当基础设施 |
| 是否含产品自有的领域模型与生命周期？ | 是——站点、目录、内容、编排、发布版本 |
| 是否跨产品复用同一份数据？ | 否——每站点数据独立，租户隔离 |

→ 归入**产品层**（`0-1` §二），复用中台依赖按 `4-1` 强制清单执行。

## 依赖声明（`docs/services/README.md` 使用规则要求）

| 类型 | 依赖 | 用途 |
|---|---|---|
| 平台基础能力 | JWT 中间件 / 租户底座 / 会话 | 认证与 `tenant_id` 注入，不自建登录 |
| 平台基础能力 | 权限组 + 菜单 seed | 站点级运营权限与后台菜单注册 |
| 平台基础能力 | 文件中心 `file.proto` | 媒体上传与引用（图片不自建存储） |
| 平台基础能力 | 操作审计 | 所有写操作记录（不自建审计表） |
| 平台基础能力 | 套餐与配额 | 站点数、内容条目数、媒体容量计量 |
| 平台基础能力 | 通知中心 / Webhook | 租户暂停、注销时清理站点数据 |
| 业务中台 | 无 | 当前不依赖任何业务中台能力 |
