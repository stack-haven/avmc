## 一、设计原则

Evie 作为产品服务，**不重复造轮子**，所有租户管理能力复用以 Ark Tech Platform 技术中台的**租户底座**。

| 维度 | 复用策略 |
|------|---------|
| 租户标识 | 使用平台统一 `tenant_id`，从 JWT auth context 提取 |
| 租户生命周期 | 不自己管理，由平台租户底座负责 |
| 认证 | 复用平台 JWT，Service 层注入提取 |
| 权限 | 平台权限码 + Evie 自身资源权限 |
| 配额 | 调用平台套餐配额 API |

---

## 二、数据隔离层次

```
应用层     Service 层提取 tenant_id，不信任客户端传入
  │
数据库层   Ent query 强制 where tenant_id
  │
缓存层     Redis Key 前缀: dict:{tenantID}:...
  │
检索层     ES query 添加 filter: tenant_id
  │
向量层     Milvus search 添加 expr: tenant_id == X
```

## 三、Service 层 — tenant_id 提取（强制）

```go
// internal/service/middleware.go
// 所有 Evie 接口统一从 auth context 提取 tenant_id

func TenantIDFromContext(ctx context.Context) (string, error) {
    claims, ok := auth.FromContext(ctx)
    if !ok {
        return "", errcode.Unauthorized("missing auth context")
    }
    if claims.TenantID == "" {
        return "", errcode.Forbidden("tenant_id not found in token")
    }
    return claims.TenantID, nil
}

// 在 Service 层入口统一提取
func (s *DictionaryService) ListWords(ctx context.Context, req *pb.ListWordsRequest) (*pb.ListWordsResponse, error) {
    tenantID, err := TenantIDFromContext(ctx)
    if err != nil {
        return nil, err
    }
    // 永远不相信客户端传入的 tenant_id
    // 使用从 JWT 提取的 tenantID
    return s.uc.ListWords(ctx, tenantID, req)
}
```

## 四、数据库层 — Ent 查询强制过滤

### 4.1 Data 层封装

```go
// internal/data/dictionary.go

type DictionaryRepo struct {
    client *ent.Client
}

// 所有 repo 方法强制传入 tenantID
func (r *DictionaryRepo) FindWords(ctx context.Context, tenantID string, filter WordFilter) ([]*ent.DictionaryWord, error) {
    query := r.client.DictionaryWord.Query().
        Where(dictionaryword.TenantIDEQ(tenantID)) // 强制过滤

    if filter.Category != "" {
        query = query.Where(dictionaryword.CategoryEQ(filter.Category))
    }
    if filter.Status != nil {
        query = query.Where(dictionaryword.StatusEQ(*filter.Status))
    }

    return query.All(ctx)
}

// 平台级词（tenant_id=0）对所有租户可见
func (r *DictionaryRepo) FindPlatformWords(ctx context.Context) ([]*ent.DictionaryWord, error) {
    return r.client.DictionaryWord.Query().
        Where(dictionaryword.TenantIDEQ(0)).
        Where(dictionaryword.StatusEQ(1)).
        All(ctx)
}

// 合并查询：平台词 + 租户词，租户词优先级更高
func (r *DictionaryRepo) FindAllForTenant(ctx context.Context, tenantID string, filter WordFilter) ([]*DictionaryEntry, error) {
    platform, _ := r.FindPlatformWords(ctx)
    tenant, _ := r.FindWords(ctx, tenantID, filter)

    // 合并去重：租户词覆盖平台词（按 word 字段）
    merged := mergeDicts(platform, tenant)
    return merged, nil
}
```

### 4.2 Ent Schema 要求

所有租户数据表必须包含 `tenant_id` 字段，并建立索引：

```go
func (DictionaryWord) Fields() []ent.Field {
    return []ent.Field{
        field.Int64("tenant_id"),  // 必须字段
        // ...
    }
}

func (DictionaryWord) Indexes() []ent.Index {
    return []ent.Index{
        index.Fields("tenant_id", "word").Unique(), // 租户级别唯一索引
        index.Fields("tenant_id", "status"),         // 常用查询索引
    }
}
```

## 五、缓存层 — Redis Key 隔离

```go
// internal/data/cache.go

// Key 命名规范: {模块}:{tenantID}:{资源类型}:{标识}
const (
    KeyPatternWord      = "evie:dict:%d:word:%s"      // 标准词缓存
    KeyPatternAlias     = "evie:dict:%d:alias:%s"     // 别名缓存
    KeyPatternPinyin    = "evie:dict:%d:pinyin:%s"    // 拼音索引缓存
    KeyPatternRule      = "evie:correction:rule:%d"   // 规则缓存
    KeyPatternHotword   = "evie:asr:hotword:%d"       // 热词缓存
    KeyPatternSession   = "evie:session:%d:%s"        // 会话缓存
)

// 批量清除租户缓存
func (c *DictCache) InvalidateTenant(ctx context.Context, tenantID int64) error {
    pattern := fmt.Sprintf("evie:dict:%d:*", tenantID)
    iter := c.rdb.Scan(ctx, 0, pattern, 1000).Iterator()
    for iter.Next(ctx) {
        c.rdb.Del(ctx, iter.Val())
    }
    return iter.Err()
}
```

### 缓存策略

| 数据类型 | TTL | 更新策略 |
|---------|-----|---------|
| 字典词 → 别名映射 | 1h | 写时失效（cache-aside） |
| 拼音索引 | 30min | 定时重建 |
| 纠错规则 | 10min | 管理员变更时失效 |
| 热词 | 5min | 实时 push |
| 会话上下文 | 30min | 按 session 生命周期 |

## 六、Elasticsearch 层 — 索引隔离

### 方案：统一索引 + tenant_id 过滤

```go
// internal/data/es.go

func (r *ESDictRepo) buildQuery(tenantID int64, text string) elastic.Query {
    return elastic.NewBoolQuery().
        // 强制租户过滤
        Filter(elastic.NewBoolQuery().
            Should(
                elastic.NewTermQuery("tenant_id", tenantID),  // 租户自有词
                elastic.NewTermQuery("tenant_id", 0),         // 平台级词（对所有租户可见）
            ),
        ).
        // 文本匹配
        Must(elastic.NewMultiMatchQuery(text, "alias^3", "word^2", "alias.pinyin^1.5", "word.pinyin^1"))
}
```

### 搜索时的权限控制

```go
func (r *ESDictRepo) Search(ctx context.Context, tenantID int64, req SearchRequest) (*SearchResult, error) {
    if tenantID == 0 {
        return nil, errcode.Forbidden("platform admin must specify tenant context")
    }

    query := r.buildQuery(tenantID, req.Text)
    // 不允许无 tenentID 查询
    return r.client.Search().
        Index("evie_dictionary").
        Query(query).
        From(req.Offset).
        Size(req.Limit).
        Do(ctx)
}
```

## 七、Milvus 层 — 向量检索隔离

### 方案：metadata 过滤（推荐）

统一 Collection，通过 search 时的 `expr` 参数做租户过滤。

```go
func (r *MilvusDictRepo) SearchSemantic(ctx context.Context, tenantID int64, text string, topK int) ([]DictionaryEntry, error) {
    vector, _ := r.embed(ctx, text)

    results, err := r.client.Search(ctx, milvus.SearchRequest{
        CollectionName: "evie_dictionary",
        Vectors:        [][]float32{vector},
        TopK:           topK,
        // 租户隔离：只搜索当前租户的词
        Expr:           fmt.Sprintf(`tenant_id == %d`, tenantID),
        OutputFields:   []string{"word_id", "word", "type", "category", "weight"},
    })
    // ...
}
```

### 备选方案：Collection 隔离（大型企业专用）

```
evie_dict_tenant_10001
evie_dict_tenant_10002
```

| 方案 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| metadata 过滤 | 管理简单、共享索引 | 大量租户时查询可能变慢 | SaaS 默认 |
| Collection 隔离 | 物理隔离、性能好 | 管理复杂、资源消耗大 | 大客户专用 |

## 八、文件隔离

语音文件存储复用以平台**文件中心**。

```go
// audio/recordings 存储路径
// {bucket}/{tenant_id}/{date}/{session_id}.{ext}
const audioPathPattern = "evie-audio/%d/%s/%s.wav"

func (s *ASRService) SaveAudio(ctx context.Context, tenantID int64, sessionID string, data []byte) (string, error) {
    key := fmt.Sprintf(audioPathPattern, tenantID, time.Now().Format("2006-01-02"), sessionID)
    // 调用平台文件中心上传
    url, err := s.fileClient.Upload(ctx, key, data, "audio/wav")
    return url, err
}
```

## 九、平台管理员跨租户操作

```go
// 平台管理员可以指定操作的租户上下文
func (s *DictionaryService) AdminListWords(ctx context.Context, req *pb.AdminListWordsRequest) (*pb.ListWordsResponse, error) {
    claims, _ := auth.FromContext(ctx)

    // 检查是否为平台管理员
    if !claims.IsPlatformAdmin {
        return nil, errcode.Forbidden("platform admin only")
    }

    // 管理员可以跨租户查询（使用请求中指定的 tenant_id）
    tenantID := req.TenantId
    if tenantID == "" {
        return nil, errcode.BadRequest("tenant_id required for admin query")
    }

    // 审计日志
    audit.Log(ctx, "evie.dictionary.admin_list", map[string]interface{}{
        "operator":   claims.UserID,
        "target_tenant": tenantID,
    })

    return s.uc.ListWords(ctx, tenantID, req)
}
```

## 十、安全设计清单

| 检查项 | 要求 | 实现方式 |
|-------|------|---------|
| tenant_id 来源 | 仅从 JWT 提取 | `TenantIDFromContext(ctx)` |
| 客户端传入 tenant_id | 忽略或校验与 JWT 一致 | Service 层覆盖 |
| 数据查询 | 强制 where tenant_id | Data 层封装，无遗漏 |
| 缓存 key | 包含 tenant_id | Key pattern 约束 |
| ES 查询 | Filter tenant_id | BoolQuery Filter |
| Milvus 查询 | expr tenant_id == X | Search expr |
| 文件存储 | 租户目录隔离 | 文件中心 key pattern |
| 管理端跨租户 | 平台管理员 + 审计 | Admin API + audit.Log |
| 租户删除 | 级联清理所有数据 | 异步任务 |
