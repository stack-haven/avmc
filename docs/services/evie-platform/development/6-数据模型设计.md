## 一、Ent 目录结构

沿用 `platform/admin` 的 ent 分层模式：**pkg 公共层 + 服务层组合**。

```

├── pkg/entgo/mixin/                       ← 🔷 公共层（已有，零改动）

│   ├── time.go            CreatedAt / UpdatedAt / DeletedAt / TimeAt
│   ├── status.go          Status (0=未知 1=启用 2=禁用)
│   ├── tenant_id.go       TenantID (纯字段)
│   ├── sort.go / remark.go / state.go ...
│   └── paging/            分页工具

├── app/evie/internal/data/ent/
│   ├── schema/                            ← 🔶 业务 Schema（只写业务字段）
│   │   ├── dictionary_word.go
│   │   ├── dictionary_alias.go
│   │   ├── correction_rule.go
│   │   ├── correction_log.go
│   │   ├── correction_feedback.go
```

## 二、Mixin 复用模型

Schema 只定义业务字段，基础设施字段（id、时间戳、状态、tenant_id）全部由 mixin 注入。

```
Schema 声明                        实际生成的表字段
─────────────────────              ─────────────────
Fields() {                         id                  ← mixins.BaseMixin (pkg.ID)
    word                           tenant_id           ← mixins.BaseMixin (pkg.TenantID)
    type                           status              ← mixins.BaseMixin (pkg.Status)
    category                       created_at          ← mixins.BaseMixin (pkg.TimeAt.CreatedAt)
    ...                            updated_at          ← mixins.BaseMixin (pkg.TimeAt.UpdatedAt)
}                                  deleted_at          ← mixins.SoftDeleteMixin（可选）
                                   │                   │
Mixin() {                          │                   │
    mixins.BaseMixin{}             │← 字段来源          │← 字段来源
    mixins.SoftDeleteMixin{}       │                   │
}                                  │                   │
Indexes() {                        索引               索引
    index.Fields("tenant_id", "word").Unique()
}
```

### 各表 Mixin 使用策略

| Schema | BaseMixin | SoftDeleteMixin | 原因 |
|--------|:---:|:---:|------|
| dictionary_word | ✅ | ✅ | 字典词允许停用后保留，支持恢复 |
| dictionary_alias | ✅ | ✅ | 别名随 word 软删除 |
| correction_rule | ✅ | ✅ | 规则停用后保留历史 |
| correction_log | ✅ | ❌ | 只追加、不删除（审计日志） |
| correction_feedback | ✅ | ❌ | 只追加、不删除 |
| asr_record | ✅ | ❌ | 只追加、不删除 |
| hotword | ✅ | ❌ | 热词直接删即可（无关联） |
| dict_sync_log | ✅ | ❌ | 只追加、不删除 |
| asr_provider_config | ✅ | ❌ | 租户 ASR 供应商配置 |
| data_source | ✅ | ❌ | 字典数据源集成 |

## 四、服务层 Mixin 实现（参考 platform/admin cp）

### 4.1 base.go — 组装 pkg 原子零件

```go
// internal/data/ent/mixins/base.go
package mixins

import (
    pkgMixin "backend-service/pkg/entgo/mixin"
    "entgo.io/ent"
    "entgo.io/ent/schema/mixin"
)

type BaseMixin struct{ mixin.Schema }

func (BaseMixin) Fields() []ent.Field {
    var fields []ent.Field
    fields = append(fields, pkgMixin.ID{}.Fields()...)       // id: bigint, 自增
    fields = append(fields, pkgMixin.CreatedAt{}.Fields()...) // created_at
    fields = append(fields, pkgMixin.UpdatedAt{}.Fields()...) // updated_at
    fields = append(fields, pkgMixin.Status{}.Fields()...)    // status: tinyint(2)
    fields = append(fields, TenantID{}.Fields()...)           // tenant_id + Policy
    return fields
}

func (BaseMixin) Indexes() []ent.Index {
    return TenantID{}.Indexes()
}

func (BaseMixin) Policy() ent.Policy {
    return TenantID{}.Policy()
}
```

### 4.2 tenant_id.go — 字段 + 租户隔离策略

```go
// internal/data/ent/mixins/tenant_id.go
package mixins

import (
    "backend-service/app/evie/internal/data/ent/rule"
    "entgo.io/ent"
    "entgo.io/ent/dialect"
    "entgo.io/ent/schema/field"
    "entgo.io/ent/schema/index"
    "entgo.io/ent/schema/mixin"
)

type TenantID struct{ mixin.Schema }

func (TenantID) Fields() []ent.Field {
    return []ent.Field{
        field.Uint32("tenant_id").
            Comment("租户ID").
            Positive().
            StructTag(`json:"tenant_id,omitempty"`).
            SchemaType(map[string]string{
                dialect.MySQL:    "bigint",
                dialect.Postgres: "bigint",
            }),
    }
}

func (TenantID) Indexes() []ent.Index {
    return []ent.Index{index.Fields("tenant_id")}
}

func (TenantID) Policy() ent.Policy {
    return rule.FilterTenantRule() // ← type-switch 本服务所有 gen 类型
}
```

```go
// internal/data/ent/schema/dictionary_word.go
package schema

import (
    "backend-service/app/evie/internal/data/ent/mixins"
    "entgo.io/ent"
    "entgo.io/ent/dialect/entsql"
    "entgo.io/ent/schema"
    "entgo.io/ent/schema/edge"
    "entgo.io/ent/schema/field"
    "entgo.io/ent/schema/index"
)

type DictionaryWord struct{ ent.Schema }

func (DictionaryWord) Annotations() []schema.Annotation {
    return []schema.Annotation{
        entsql.Annotation{Charset: "utf8mb4", Collation: "utf8mb4_bin", Table: "evie_dictionary_words"},
        entsql.WithComments(true),
        schema.Comment("语音字典标准词表"),
    }
}

func (DictionaryWord) Fields() []ent.Field {
    return []ent.Field{
        field.String("word").MaxLen(128).NotEmpty().Comment("标准词"),
        field.String("type").Default("tenant").Comment("platform/system/tenant/user"),
        field.String("category").Default("term").Comment("person/org/product/term"),
        field.String("source").Default("manual").Comment("manual/sync_org/sync_biz/feedback"),
        field.Int("priority").Default(0).Comment("匹配优先级，越大越优先"),
    }
}

func (DictionaryWord) Edges() []ent.Edge {
    return []ent.Edge{
        edge.To("aliases", DictionaryAlias.Type),
    }
}

func (DictionaryWord) Mixin() []ent.Mixin {
    return []ent.Mixin{
        mixins.BaseMixin{},
        mixins.SoftDeleteMixin{},
    }
}

func (DictionaryWord) Hooks() []ent.Hook {
    return nil // 如需跨租户外键校验，参考 platform/admin rule.DictionaryItemTenantHook()
}

func (DictionaryWord) Indexes() []ent.Index {
    return []ent.Index{
        index.Fields("tenant_id", "word").Unique(),
        index.Fields("tenant_id", "type", "category"),
        index.Fields("word"),
    }
}
```

## 七、租户隔离策略（自动生效）

所有嵌入 `mixins.BaseMixin{}` 的 Schema 自动获得以下行为：

| 操作 | 行为 |
|------|------|
| **Create** | 自动注入 `tenant_id`（从 viewer context），客户端无需传入 |
| **Read** | 自动添加 `WHERE tenant_id = ?`（从 viewer context），除非 `IsSystem(ctx)` |
| **Update** | 自动添加 `WHERE tenant_id = ?`，禁止修改 `tenant_id` |
| **Delete** | 自动添加 `WHERE tenant_id = ?`；若嵌入 `SoftDeleteMixin` 则 UPDATE `deleted_at` 而非物理删除 |
