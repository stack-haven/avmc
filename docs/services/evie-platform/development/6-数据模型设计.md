| 表名（Ent Schema） | MySQL 表名 | 归属模块 | Mixin |
|------------------|-----------|---------|-------|
| `Dictionary` | `evie_dictionaries` | 词库中心 | BaseMixin + SoftDelete |
| `DictionaryEntry` | `evie_dictionary_entries` | 词库中心 | BaseMixin + SoftDelete |
| `DictionaryRelation` | `evie_dictionary_relations` | 词库中心 | BaseMixin + SoftDelete |
| `DictionaryCategory` | `evie_dictionary_categories` | 词库中心 | BaseMixin |
| `DictionaryVersion` | `evie_dictionary_versions` | 词库中心 | BaseMixin |
| `DictionaryConflict` | `evie_dictionary_conflicts` | 词库中心 | BaseMixin |
| `DictionaryChangeLog` | `evie_dictionary_change_logs` | 词库中心 | BaseMixin（只追加） |
| `EnhancementPolicy` | `evie_enhancement_policies` | 文本增强引擎 | BaseMixin |
| `EnhancementProfile` | `evie_enhancement_profiles` | 文本增强引擎 | BaseMixin |

| `AsrProviderConfig` | `evie_asr_provider_configs` | ASR | BaseMixin |

所有表继承 `BaseMixin`（`id` + `tenant_id` + `status` + `created_at` + `updated_at`）；

## 二、词库中心表（7 张）

### 2.1 Dictionary（词库）

```go
// app/evie/service/internal/data/ent/schema/dictionary.go
type Dictionary struct{ ent.Schema }

func (Dictionary) Fields() []ent.Field {
    return []ent.Field{
        field.String("name").MaxLen(128).NotEmpty().Comment("词库名称"),
        field.Enum("scope").Values("PLATFORM", "SYSTEM", "TENANT").Default("TENANT").Comment("作用域"),
        field.Enum("source").Values("MANUAL", "IMPORT", "SYNC", "API").Default("MANUAL").Comment("来源"),
        field.String("description").Optional().MaxLen(512).Comment("描述"),
    }
}

func (Dictionary) Indexes() []ent.Index {
    return []ent.Index{
        index.Fields("tenant_id", "name").Unique(),                  // 租户内唯一
        index.Fields("tenant_id", "scope", "status"),                // VocabularyContext 查询索引
    }
}
```

**核心语义**：
- `scope=PLATFORM`：`tenant_id=0`，全局共享（所有租户可见，但只在 platform 范围下可管理）
- `scope=SYSTEM`：跟随系统租户
- `scope=TENANT`：租户私有

### 2.2 DictionaryEntry（词条）

```go
type DictionaryEntry struct{ ent.Schema }

func (DictionaryEntry) Fields() []ent.Field {
    return []ent.Field{
        field.Uint32("dictionary_id").Positive().Comment("所属词库 ID"),
        field.String("standard_text").MaxLen(128).NotEmpty().Comment("标准词/短语"),
        field.Enum("entry_type").Values("WORD", "PHRASE").Default("WORD").Comment("词条类型"),
        field.Enum("category").Values(
            "PERSON", "ORGANIZATION", "PRODUCT", "TERM",
            "LOCATION", "INDUSTRY", "BRAND", "CUSTOM",
        ).Default("TERM").Comment("实体分类"),
        field.String("description").Optional().MaxLen(512),
        field.Enum("source").Values("MANUAL", "IMPORT", "SYNC", "API").Default("MANUAL"),
        field.String("source_id").Optional().MaxLen(128).Comment("外部来源 ID"),
        field.Int("priority").Default(0).Comment("优先级，越大越优先"),
        field.String("pinyin").Optional().MaxLen(256).Comment("全拼"),
        field.String("pinyin_initial").Optional().MaxLen(64).Comment("拼音首字母"),
        field.String("normalized_text").Optional().MaxLen(128).Comment("规范化文本"),
    }
}

func (DictionaryEntry) Indexes() []ent.Index {
    return []ent.Index{
        index.Fields("tenant_id", "dictionary_id", "standard_text").Unique(),
        index.Fields("tenant_id", "category"),
        index.Fields("tenant_id", "pinyin"),
    }
}
```

### 2.3 DictionaryRelation（词条关系）

```go
type DictionaryRelation struct{ ent.Schema }

func (DictionaryRelation) Fields() []ent.Field {
    return []ent.Field{
        field.Uint32("entry_id").Positive().Comment("所属词条 ID"),
        field.Enum("relation_type").Values(
            "ALIAS",          // 别名
            "CORRECTION",     // 纠错
            "HOMOPHONE",      // 同音
            "PHONETIC_SIMILAR", // 音近
            "ABBREVIATION",   // 缩写
            "RELATED",        // 相关
        ).Comment("关系类型"),
        field.String("related_text").MaxLen(128).NotEmpty().Comment("关联表达"),
        field.Uint32("target_entry_id").Optional().Positive().Comment("目标词条 ID（同义词必填）"),
        field.String("description").Optional().MaxLen(256),
    }
}
```

> `ALIAS` 关系承担原「热词」职责：识别文本中遇到 `related_text` 时，映射到 `entry_id` 对应的标准词。

### 2.4 DictionaryCategory（分类）

### 2.5 DictionaryVersion（版本快照）

```go
type DictionaryVersion struct{ ent.Schema }

func (DictionaryVersion) Fields() []ent.Field {
    return []ent.Field{
        field.Uint32("dictionary_id").Positive().Comment("所属词库 ID"),
        field.String("version_no").MaxLen(32).NotEmpty().Comment("版本号，如 v1.2.0"),
        field.String("description").Optional().MaxLen(512).Comment("发布说明"),
        field.Enum("status").Values("DRAFT", "PUBLISHED", "ARCHIVED").Default("DRAFT"),
        field.JSON("snapshot", map[string]any{}).Comment("发布时刻快照 JSON"),
    }
}
```

发布（PublishDictionary RPC）时把当前词条/关系全量序列化为 snapshot JSON，便于回溯和回滚。

### 2.6 DictionaryConflict（冲突记录）

type DictionaryConflict struct{ ent.Schema }

        field.JSON("candidates", []any{}).Comment("候选结果列表"),
        field.Enum("source_scope").Values("PLATFORM", "SYSTEM", "TENANT").Comment("来源作用域"),

跨作用域优先级冲突（同一表达在 PLATFORM 和 TENANT 都有匹配）写入此表，等待人工裁决。

## 三、文本增强引擎表（3 张）

### 3.1 EnhancementPolicy（增强策略）

```go
type EnhancementPolicy struct{ ent.Schema }

func (EnhancementPolicy) Fields() []ent.Field {
    return []ent.Field{
        field.String("name").MaxLen(64).NotEmpty().Comment("策略名称"),
        field.Enum("mode").Values("HIGH_PERFORMANCE", "STANDARD", "HIGH_ACCURACY").Default("STANDARD"),
        field.Bool("enable_text_cleaning").Default(true).Comment("文本清洗"),
        field.Bool("enable_filler_removal").Default(true).Comment("口水词处理"),
        field.Bool("enable_alias_resolution").Default(true).Comment("别名解析"),
        field.Bool("enable_deterministic_replacement").Default(true).Comment("确定性替换"),
        field.Bool("enable_pinyin_correction").Default(true).Comment("拼音纠错"),
        field.Bool("enable_fuzzy_matching").Default(true).Comment("模糊匹配"),
        field.Bool("enable_context_correction").Default(false).Comment("上下文纠错（高负载）"),
        field.String("description").Optional().MaxLen(256),
    }
}
```

策略 8 个开关对应 8 层流水线；mode 是预设开关组合：
- HIGH_PERFORMANCE：关掉上下文纠错 + 模糊匹配，保留确定性强项
- STANDARD：默认全部开启
- HIGH_ACCURACY：开启全部 + 调高 threshold

### 3.2 EnhancementProfile（增强场景）

```go
type EnhancementProfile struct{ ent.Schema }

func (EnhancementProfile) Fields() []ent.Field {
    return []ent.Field{
        field.String("name").MaxLen(64).NotEmpty().Comment("场景名称，如「客服对话」「会议记录」"),
        field.Uint32("policy_id").Positive().Comment("绑定的策略 ID"),
        field.String("description").Optional().MaxLen(256),
    }
}
```

Profile 绑定 Policy：同一 Policy 可被多个 Profile 复用，Profile 是「业务场景」层抽象。

### 3.3 EnhancementLog（增强记录）

```go
type EnhancementLog struct{ ent.Schema }

func (EnhancementLog) Fields() []ent.Field {
    return []ent.Field{
        field.Uint32("user_id").Optional().Comment("用户 ID"),
        field.String("session_id").MaxLen(64).Optional().Comment("会话 ID"),
        field.Uint32("profile_id").Optional().Positive().Comment("使用的 Profile ID"),
        field.String("raw_text").NotEmpty().Comment("原文"),
        field.String("enhanced_text").NotEmpty().Comment("增强后文本"),
        field.JSON("changes_json", []any{}).Comment("变更列表"),
        field.Int64("processing_time_ms").Default(0).Comment("总耗时"),
        // 8 个分阶段耗时字段（与策略开关对应）
        field.Int64("cleaning_time_ms").Default(0),
        field.Int64("filler_time_ms").Default(0),
        field.Int64("vocab_match_time_ms").Default(0),
        field.Int64("alias_time_ms").Default(0),
        field.Int64("deterministic_time_ms").Default(0),
        field.Int64("pinyin_time_ms").Default(0),
        field.Int64("fuzzy_time_ms").Default(0),
        field.Int64("context_time_ms").Default(0),
        // 降级标记
        field.Enum("status").Values("SUCCESS", "DEGRADED", "FAILED").Default("SUCCESS"),
        field.String("error_message").Optional().MaxLen(512),
    }
}
```

降级策略：单阶段失败不阻断，仅记 error_message 并把 status 标为 DEGRADED；
8 个阶段耗时便于性能分析和优化。

## 五、词汇库合并（VocabularyContext）

构建逻辑见 `app/evie/service/internal/biz/vocabulary.go`：

```
PLATFORM 词库（tenant_id=0, scope=PLATFORM）
  ↓ 合并
SYSTEM 词库（tenant_id=sys, scope=SYSTEM）
  ↓ 合并
TENANT 词库（tenant_id=tenant, scope=TENANT）

优先级: TENANT > SYSTEM > PLATFORM
同名冲突 → DictionaryConflict 记录 + 人工裁决
```

构建产物 `VocabularyContext` 是文本增强引擎各步骤的输入；缓存由 sync.Map + version 失效。

## 六、字段来源汇总

| 字段 | 来源 Mixin | 说明 |
|------|-----------|------|
| `id` | `pkg/entgo/mixin.ID` | uint32 bigint, 自增, unique, immutable |
| `tenant_id` | `pkg/entgo/mixin.TenantID` | uint32 bigint, positive, 强制租户隔离 |
| `status` | `pkg/entgo/mixin.Status` | int32, 0=未知 1=启用 2=禁用 |
| `created_at` | `pkg/entgo/mixin.CreatedAt` | time.Now, immutable |
| `updated_at` | `pkg/entgo/mixin.UpdatedAt` | time.Now, UpdateDefault |
| `deleted_at` | `pkg/entgo/mixin.SoftDeleteMixin` | 可选，仅词库/词条/关系支持 |

## 七、租户隔离策略（自动生效）

所有嵌入 `BaseMixin{}` 的 Schema 自动获得以下行为：

| 操作 | 行为 |
|------|------|
| **Create** | 自动注入 `tenant_id`（从 auth context），客户端无需传入 |
| **Read** | 自动添加 `WHERE tenant_id = ?`，除非 ctx 是 platform 身份 |
| **Update** | 自动添加 `WHERE tenant_id = ?`，禁止修改 `tenant_id` |
| **Delete** | 自动添加 `WHERE tenant_id = ?`；若嵌入 SoftDeleteMixin 则 UPDATE `deleted_at` |

---

## 八、缓存策略

| 数据类型 | 位置 | 失效策略 |
|---------|------|---------|
| VocabularyContext | 进程内 sync.Map（`VocabularyBuilder.Build`） | 词库写入触发 context_version bump |
| EnhancementPolicy/Profile | 可选 Redis（`pkg/cache`） | 写时失效（cache-aside） |
| AsrRecord | MySQL 持久化即可 | 不预热 |
| 音频文件 | 平台文件中心 | 走平台存储生命周期 |

不再使用 ES / Milvus：
- 语义检索 = 文本增强引擎「模糊匹配」+「上下文纠错」步骤
- 全文检索 = 文本增强引擎「词库匹配」+「别名解析」步骤

## 九、Atlas 迁移规范

所有表通过 Atlas 迁移管理，**不手工改表**：

```bash
cd backend-service
# 1. 修改 ent/schema/*.go 后生成代码
make generate

# 2. 生成迁移文件（自动 diff）
make migrate-diff NAME=evie_add_dictionary_change_log

# 3. 提交迁移文件 + schema 改动到 backend-service 仓库

# 4. 部署时自动执行 migrate
make migrate-up
```
