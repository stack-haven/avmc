# **应用版本管理中心 - UI 功能详细说明文档 v1.0.0**

## **1. 系统概述**

本系统是面向多项目的应用更新管理平台，涵盖版本管理、应用下载页配置、灰度发布、用户反馈、协议管理、推送通知、用户管理等模块。本文档为每个模块提供 UI 功能说明及相关字段设计，帮助开发团队高效实现功能。

---

## **2. 模块功能设计**

### **2.0 项目管理模块**

#### **功能说明**

-   提供项目的新增、编辑、删除功能。
-   支持管理员配置不同用户对项目的访问权限。

#### **UI 设计**

1.  **项目列表页面**

    -   功能：展示已创建的所有项目信息。
    -   栏目字段：
        -   项目名称（`project_name`）
        -   项目描述（`project_description`）
        -   创建时间（`created_at`）
    -   操作按钮：
        -   **查看**：查看项目详细信息。
        -   **编辑**：修改项目内容。
        -   **删除**：删除项目。
        -   **权限配置**：配置项目权限。

2.  **新增/编辑项目页面**

    -   表单字段：
        -   项目名称（`project_name`）：文本框，格式校验。
        -   项目描述（`project_description`）：文本框。
        -   项目负责人（`project_owner`）：下拉框，选择用户。

3.  **权限配置页面**

    -   功能：配置不同用户对项目的访问权限。
    -   列表字段：
        -   用户名（`username`）
        -   角色（`role`）：下拉框，选择角色（管理员/开发者/运营）。
        -   权限（`permissions`）：复选框，选择权限。

4.  **字段设计**
    -   `project_name`：字符串，项目名称。
    -   `project_description`：文本，项目描述。
    -   `project_owner`：整型，项目负责人 ID。
    -   `project_status`：字符串，项目状态（例如：启用、禁用、维护中）。
    -   `project_logo`：字符串，项目 Logo 图片链接。
    -   `project_create_user`：整型，创建项目用户 ID。
    -   `username`：字符串，用户名。
    -   `role`：枚举，用户角色（管理员/开发者/运营）。
    -   `permissions`：数组，用户权限列表。

### **2.1 版本管理模块**

#### **功能说明**

-   提供版本新增、更新检测、资源包更新、整包更新及回滚功能。
-   支持强制更新和静默更新两种方式。
-   跨版本更新自动切换为整包更新。
-   **版本管理基于项目**

#### **UI 设计**

1.  **版本列表页面**

    -   功能：展示已发布的所有版本信息。
    -   栏目字段：
        -   **项目名称（`project_name`）**
        -   版本号（`version_code`）
        -   版本名称（`version_name`）
        -   版本类型（整包/资源包）
        -   发布时间（`release_date`）
        -   状态（已发布/草稿）
    -   操作按钮：
        -   **查看**：查看详细信息。
        -   **编辑**：修改版本内容。
        -   **回滚**：回滚至此版本。
        -   **发布 Release**：发布 Release。

2.  **新增/编辑版本页面**

    -   表单字段：
        -   **项目选择（`project_id`）：下拉框。**
        -   版本号（`version_code`）：文本框，格式校验。
        -   版本名称（`version_name`）：文本框。
        -   更新说明（`update_description`）：富文本框。
        -   更新类型（`update_type`）：单选框（整包/资源包）。
        -   更新包上传（`update_file`）：文件上传控件。
        -   灰度发布设置（`gray_release`）：复选框。

3.  **字段设计**
    -   `project_id`：整型，项目 ID。
    -   `version_code`：字符串，版本号。
    -   `version_name`：字符串，版本名称。
    -   `version_description`：文本，描述更新内容。
    -   `version_min_sdk`：整型，最低支持的 SDK 版本。
    -   `version_target_sdk`：整型，目标 SDK 版本。
    -   `version_package_name`：字符串，应用包名。
    -   `version_build_number`：整型，构建版本号。
    -   `version_release_notes`：文本，版本发布说明，可以使用富文本或 Markdown 格式。
    -   `version_is_force_update`：布尔值，是否强制更新。
    -   `version_is_silent_update`：布尔值，是否静默更新。
    -   `version_download_url`：字符串，下载链接地址，可以支持多个下载链接，例如不同平台的下载链接。
    -   `version_file_size`：整型，文件大小，单位为字节。
    -   `version_md5`：字符串，MD5 校验值。
    -   `version_sha256`：字符串，SHA256 校验值。
    -   `update_type`：枚举，"full" 或 "resource"。
    -   `update_file`：文件路径，更新包存储地址。

### **2.1.1 Release 发布管理**

#### **功能说明**

-   提供 Release 版本的发布、更新、删除功能。
-   支持 Release 版本的灰度发布、全量发布。

#### **UI 设计**

1.  **Release 列表页面**

    -   功能：展示已发布的所有 Release 信息。
    -   栏目字段：
        -   Release 名称（`release_name`）
        -   Release 版本（`release_version`）
        -   发布时间（`release_date`）
        -   状态（已发布/草稿）
    -   操作按钮：
        -   **查看**：查看详细信息。
        -   **编辑**：修改 Release 内容。
        -   **删除**：删除 Release。
        -   **发布**：发布 Release。

2.  **新增/编辑 Release 页面**

    -   表单字段：
        -   Release 名称（`release_name`）：文本框，格式校验。
        -   Release 版本（`release_version`）：文本框。
        -   发布说明（`release_description`）：富文本框。
        -   发布类型（`release_type`）：单选框（灰度发布/全量发布）。
        -   灰度发布设置（`gray_release`）：复选框。

3.  **字段设计**
    -   `release_name`：字符串，Release 名称。
    -   `release_version`：字符串，Release 版本。
    -   `release_description`：文本，描述发布内容。
    -   `release_status`：字符串，发布状态（例如：草稿、待发布、已发布、已撤回）。
    -   `release_start_time`：时间戳，发布开始时间。
    -   `release_end_time`：时间戳，发布结束时间。
    -   `release_total_users`：整型，覆盖用户总数。
    -   `release_success_users`：整型，成功更新用户数。
    -   `release_fail_users`：整型，更新失败用户数。
    -   `release_cancel_users`：整型，取消更新用户数。
    -   `release_update_rate`：浮点型，更新成功率。
    -   `release_notes`：文本，发布说明，可以使用富文本或 Markdown 格式。
    -   `release_type`：枚举，"gray" 或 "full"。

### **2.2 应用下载页模块**

#### **功能说明**

- 动态配置下载页内容，包括应用基本信息、版本内容及活动推广信息。

#### **UI 设计**

1. **下载页配置页面**

   - 功能：选择模板并配置页面内容。
   - 栏目字段：
     - 页面名称（`page_name`）
     - 页面状态（已发布/草稿）
     - 最近修改时间（`last_updated`）
   - 操作按钮：
     - **编辑**：进入内容配置页面。
     - **预览**：实时查看页面效果。
     - **发布**：将草稿发布上线。

2. **内容编辑页面**

   - 表单字段：
     - 应用名称（`app_name`）：文本框。
     - 版本信息（`version_info`）：自动拉取版本号及更新说明。
     - 下载链接（`download_url`）：文本框，支持多版本下载地址。
     - 活动宣传内容（`promotion_content`）：图片/视频上传。
     - 模板选择（`template_id`）：下拉框选择模板样式。

3. **字段设计**
    -   `page_name`：字符串，页面名称。
    -   `last_updated`：时间戳，最近修改时间。
    -   `app_name`：字符串，应用名称。
    -   `download_url`：字符串，下载链接地址。
    -   `page_template`：字符串，页面模板类型。
    -   `page_custom_css`：文本，自定义 CSS 样式。
    -   `page_custom_js`：文本，自定义 JavaScript 代码。
    -   `page_seo_title`：字符串，SEO 标题。
    -   `page_seo_keywords`：字符串，SEO 关键词。
    -   `page_seo_description`：字符串，SEO 描述。

### **2.3 灰度发布模块**

#### **功能说明**

- 按分组逐步推送版本更新，支持发布监控和策略调整。
**权限**：管理员

#### **UI 设计**

1. **灰度分组管理页面**

   - 功能：创建分组规则，查看分组详情。
   - 栏目字段：
     - 分组名称（`group_name`）
     - 用户总数（`user_count`）
     - 创建时间（`created_at`）
   - 操作按钮：
     - **编辑分组**：调整规则。
     - **删除分组**：移除分组。

2. **灰度发布设置页面**

   - 表单字段：
     - 选择分组（`group_id`）：下拉框，选择推送分组。
     - 推送比例（`release_ratio`）：滑块，选择推送覆盖范围。
     - 发布时间（`schedule_time`）：时间选择器。

3.  **字段设计**
    -   `group_name`：字符串，分组名称。
    -   `group_description`：文本，分组描述。
    -   `group_rules`：文本，分组规则，可以使用 JSON 格式存储。
    -   `group_create_user`：整型，创建分组用户 ID。
    -   `user_count`：整型，分组包含的用户数。
    -   `release_ratio`：百分比，灰度推送比例。
    -   `release_strategy`：字符串，发布策略（例如：按用户 ID、按设备型号、按地区）。
    -   `release_exclude_users`：文本，排除用户列表，可以使用 JSON 格式存储。

### **2.4 用户反馈模块**

#### **功能说明**

- 收集用户反馈并提供处理状态的管理。
**权限**：管理员/运营

#### **UI 设计**

1. **反馈列表页面**

   - 栏目字段：
     - 用户 ID（`user_id`）
     - 反馈类型（Bug/建议）
     - 提交时间（`submitted_at`）
     - 状态（待处理/处理中/已解决）
   - 操作按钮：
     - **查看详情**：进入反馈详情页面。
     - **更改状态**：更新反馈处理进度。

2. **反馈详情页面**

   - 展示反馈内容、截图及用户评分。
   - 回复功能，管理员可回复反馈。

3.  **字段设计**
    -   `user_id`：整型，用户标识。
    -   `feedback_type`：枚举，反馈类型（Bug/建议）。
    -   `submitted_at`：时间戳，反馈提交时间。
    -   `feedback_device_info`：文本，设备信息，可以使用 JSON 格式存储。
    -   `feedback_system_version`：字符串，系统版本。
    -   `feedback_app_version`：字符串，应用版本。
    -   `feedback_contact_info`：字符串，联系方式。
    -   `feedback_images`：文本，图片列表，可以使用 JSON 格式存储。
    -   `feedback_videos`：文本，视频列表，可以使用 JSON 格式存储。
    -   `feedback_priority`：字符串，优先级（例如：高、中、低）。
    -   `feedback_assignee`：整型，处理人 ID。
    -   `feedback_resolution`：文本，解决方案。
    -   `feedback_close_time`：时间戳，关闭时间。

## **3. 技术说明与附加字段**

### **全局字段设计**

- `project_id`：整型，项目标识。
- `created_at`：时间戳，记录创建时间。
- `updated_at`：时间戳，记录更新时间。

### **系统约束**

1. 所有提交表单的字段需进行前端校验（如格式检查、必填项验证）。
2. 文件上传需支持断点续传。
