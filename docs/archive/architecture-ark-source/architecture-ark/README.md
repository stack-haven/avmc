## 架构速览

```
产品层    GEO · SEO · CRM · ERP · ...
  │               调用 │ 注册接入
  ▼                    ▼
业务中台  渠道管理 · 客户运营 · 佣金结算 · 产品注册中心
  │
  ▼
技术中台  P0 核心  租户底座 · 认证权限 · 计费引擎 · 消息通知 · 文件存储 · 审计日志 · API网关 · 配置中心
         P1 完整  审批引擎 · 任务调度
         P2 规模  搜索服务 · 国际化 · 可观测性 · 开发者平台
  │
  ▼
基础设施  数据库 · 缓存 · 队列 · 对象存储 · 搜索引擎
```

## 核心设计原则

1. **中台不包含业务逻辑** — 技术中台和业务中台只提供通用能力，产品特有的逻辑在各自产品服务中实现
2. **产品线注册制** — 新产品上线只需在注册中心配置（产品信息、菜单、定价、配额），不改中台代码
3. **产品间数据隔离** — 产品 A 不能直接访问产品 B 的数据库，跨产品数据交换走 API
4. **统一计费不绑定产品** — 计费引擎提供通用框架，各产品注册自己的配额维度和超额规则
5. **统一认证 + 跨租户身份切换** — 所有用户一个认证体系，业务员可模拟客户身份操作
